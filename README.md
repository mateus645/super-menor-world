# Super Menor World

Jogo de plataforma em pixel art, 2 mundos e 8 fases. Abra o `index.html` no navegador (ou pelo link do GitHub Pages).

- Teclado: setas andam, espaço pula, X corre e solta espuma, Esc pausa, M liga e desliga o som.
- Celular: botões na tela.
- O jogo roda todo no arquivo: sem login, sem servidor, sem rede e sem coleta de dados. O recorde fica só no seu aparelho.
